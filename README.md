# 义利之衡

关于“先义后利”的第一人称互动剧情网页，包含开场视频、十三幅场景、逐字对白、配乐和四种结局。支持手机竖屏与横屏。

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库，建议名称 `yili-noodle-story`。
2. 解压部署包，将里面的 `index.html`、`soundtrack.js`、`scene-loader.js`、`.nojekyll`、`README.md` 和整个 `assets` 文件夹上传到仓库根目录。不要直接把 ZIP 文件上传到仓库。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
5. 分支选择 `main`，目录选择 `/(root)`，点击 **Save**。
6. 等待部署完成，以 Pages 页面显示的实际网站地址为准。

如果仓库名为 `yili-noodle-story`，地址格式为 `https://你的用户名.github.io/yili-noodle-story/`。这个地址在完成发布前不可用。

页面引用均为相对路径，可用于 GitHub Pages 的项目子目录，无需构建命令、服务器程序或 ChatGPT 登录。

## 使用

点击进入游戏观看或跳过开场。点击对白或按空格补全并继续；顶部可切换即时文字和配乐设置。背景图片会提前加载，图像准备好后再显示对应对白。

手机竖屏可操作，横屏能展示更完整的图片和视频。浏览器首次播放声音需要点击操作。

新闻取材于胖东来“擀面皮事件”；人物对白、个人去向与分支结局用于课堂教学创作。
