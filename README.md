# 义利之衡

关于“先义后利”的第一人称互动剧情网页，包含开场视频、十三幅场景、逐字对白、配乐和四种结局。

## 当前文件

- `index.html`：页面结构、剧情与交互。
- `cinema.css`：首页、汇报页、剧情页和开场控件的样式。
- `scene-loader.js`：场景预加载与解码。
- `soundtrack.js`：配乐与音量控制。
- `assets/`：网页实际使用的图片、视频、本地字体及字体许可证。

所有素材从 `assets/` 引用，不需要在仓库根目录另外放一份图片或视频。

## 使用与发布

GitHub Pages 使用 `main` 分支的 `/(root)`，无需构建命令。部署地址为 https://cici200707.github.io/yili-noodle-story/ 。

点击进入游戏观看或跳过开场。点击对白或按空格补全并继续；逐字输出时可以点击“立即显示整句”，配乐通过顶部设置控制。首次播放声音需要用户点击。进度和结局记录保存在当前浏览器中。

离线展示使用独立的“义利之衡-完整版单文件.html”，该文件内嵌当前图片、视频、字体、样式与脚本，无需附带素材文件夹。
